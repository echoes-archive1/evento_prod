📦 Variables - Storing Information

What are Variables?

Variables are containers that store data. Like labeled boxes that hold different things!

Declaring Variables

// let - for values that can change let age = 25; let name = "Alice"; let isStudent = true; // const - for values that stay the same const PI = 3.14159; const BIRTH_YEAR = 2000; // Data Types: // String: "text" // Number: 42, 3.14 // Boolean: true, false // null, undefined

Variable Calculator

String Operations

let firstName = "John"; let lastName = "Doe"; // Concatenation (joining strings) let fullName = firstName + " " + lastName; // Result: "John Doe" // Template literals (modern way) let greeting = `Hello, ${firstName}!`; // Result: "Hello, John!"

⚙️ Functions - Reusable Code Blocks

What are Functions?

Functions are reusable blocks of code that perform specific tasks. Like recipes you can use again and again!

Creating Functions

// Basic function function greet() { console.log("Hello!"); } // Function with parameters function greetPerson(name) { return `Hello, ${name}!`; } // Function with multiple parameters function add(a, b) { return a + b; } // Calling functions greet(); // "Hello!" let message = greetPerson("Alice"); // "Hello, Alice!" let sum = add(5, 3); // 8

Calculator Function

Arrow Functions (Modern Syntax)

// Arrow function (short syntax) const square = (x) => x * x; const multiply = (a, b) => { return a * b; }; console.log(square(5)); // 25 console.log(multiply(4, 3)); // 12

🔄 Loops - Repeating Actions

What are Loops?

Loops repeat code multiple times. Perfect for repetitive tasks!

For Loop

// Basic for loop for (let i = 0; i < 5; i++) { console.log("Count: " + i); } // Prints: 0, 1, 2, 3, 4 // Loop through a range for (let i = 1; i <= 10; i++) { console.log(i); }

Multiplication Table Generator

While Loop

// While loop let count = 0; while (count < 5) { console.log(count); count++; } // Do-while loop (runs at least once) let x = 0; do { console.log(x); x++; } while (x < 5);

Pattern Printer

📋 Arrays - Lists of Data

What are Arrays?

Arrays store multiple values in a single variable. Like a shopping list!

Creating and Using Arrays

// Creating an array let fruits = ["apple", "banana", "orange"]; let numbers = [1, 2, 3, 4, 5]; // Accessing elements (0-indexed) console.log(fruits[0]); // "apple" console.log(fruits[1]); // "banana" // Array properties and methods console.log(fruits.length); // 3 fruits.push("grape"); // Add to end fruits.pop(); // Remove from end fruits.unshift("mango"); // Add to start fruits.shift(); // Remove from start

Array Methods

let numbers = [1, 2, 3, 4, 5]; // forEach - loop through array numbers.forEach((num) => { console.log(num * 2); }); // map - transform each element let doubled = numbers.map(num => num * 2); // [2, 4, 6, 8, 10] // filter - keep elements that pass test let evenNumbers = numbers.filter(num => num % 2 === 0); // [2, 4] // reduce - combine to single value let sum = numbers.reduce((total, num) => total + num, 0); // 15

🎯 Objects - Structured Data

What are Objects?

Objects store related data together using key-value pairs. Like a profile card!

Creating Objects

// Creating an object let person = { name: "Alice", age: 25, city: "New York", isStudent: true }; // Accessing properties console.log(person.name); // "Alice" console.log(person["age"]); // 25 // Adding/modifying properties person.email = "alice@email.com"; person.age = 26; // Object with methods let calculator = { add: function(a, b) { return a + b; }, multiply: (a, b) => a * b };

🌐 DOM Manipulation - Interactive Websites

What is the DOM?

DOM (Document Object Model) lets you change website content dynamically with JavaScript!

Selecting Elements

// Select by ID let element = document.getElementById("myId"); // Select by class let elements = document.getElementsByClassName("myClass"); // Select by CSS selector (modern way) let element = document.querySelector(".myClass"); let allElements = document.querySelectorAll(".myClass");

Changing Content and Style

// Change text content element.textContent = "New text"; element.innerHTML = "<strong>Bold text</strong>"; // Change styles element.style.color = "red"; element.style.backgroundColor = "yellow"; element.style.fontSize = "20px"; // Add/remove classes element.classList.add("active"); element.classList.remove("hidden"); element.classList.toggle("visible");

Event Listeners

// Click event button.addEventListener("click", function() { alert("Button clicked!"); }); // Input event input.addEventListener("input", (e) => { console.log(e.target.value); }); // Mouse events element.addEventListener("mouseover", () => { element.style.backgroundColor = "lightblue"; });
